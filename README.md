## Результаты

| Входной сигнал | Длительность | Полные кадры | Матрица признаков |
| --- | ---: | ---: | ---: |
| Учебный сигнал | 2,000 с | 198 | 39 × 198 |

Для каждого кадра вычислены 13 MFCC и дельты первого и второго порядка. Базовые параметры — частота дискретизации 16 кГц, окно Хэмминга 25 мс, шаг 10 мс, БПФ на 512 точек и 26 мел-фильтров.

## Запуск

Из корневой папки проекта выполните

```sh
python -m pip install numpy scipy matplotlib
python speech_pipeline.py --synthetic
python speech_pipeline.py --wav voice.wav --out voice_results
python experiments.py --voice voice.wav
```

Учебный сигнал генерируется с фиксированным зерном 42. Личная запись подготовлена в формате моно WAV, 16 кГц. Проверенные версии библиотек и дополнительные параметры приведены в [инструкции](README.txt).
